Territory 01

Koinelio

In Progress · IIT Bhilai email-restricted pilot

A Supabase-backed campus community platform for profiles, approved clubs, student leadership, events, notifications and role-restricted club rooms.

Implemented (per README)

  • Supabase Auth sign-up restricted to confirmed @iitbhilai.ac.in accounts; sign-up can only create student profiles.
  • Persisted profile editing and avatar upload (JPG, PNG or WebP, up to 2 MB).
  • Database-backed posts, likes, comments, events, registrations, announcements and notifications.
  • Club proposals, membership requests, invitations, Core Member assignment and governance approvals.
  • Three club rooms (General, Members, Core Team) with access enforced by Row Level Security.
  • Post reporting with a moderator-only resolution flow; recruitment and elections pages exist in the app.

Stack

  • Next.js (App Router)
  • React
  • TypeScript
  • Tailwind CSS v4
  • Supabase Auth
  • Postgres RLS
  • Supabase Storage
  • pnpm

Honest limits

The README describes this as under production hardening: the access and governance migrations have not been validated on a staging database or applied to the live Supabase project, and it is not an official IIT Bhilai service. The repository includes Node test files for governance security and post classification.

Territory 02

SmartNotepad

Active development · live demo

A cloud note-taking app: write notes in a responsive editor, keep them tied to a Supabase-authenticated account, and reopen them from any device.

Implemented (per README)

  • Next.js 15 App Router with a React 19 interface and a responsive note editor.
  • Cloud notes stored in Supabase with persistent per-user data.
  • Supabase Auth for sign-in, and a demo workspace for exploring without an account.
  • Tailwind CSS interface with a typed codebase (TypeScript, ESLint, Prettier scripts).

Stack

  • Next.js 15
  • React 19
  • TypeScript
  • Tailwind CSS
  • Supabase
  • Supabase Auth
  • Vercel

Honest limits

The README calls it "actively developed" and a personal productivity project. It lists cloud notes, authentication and a responsive editor — no collaboration, sharing or publishing features are claimed.

Territory 03

ASRS — student record system

Demo · role-based student records

An attendance and academic-records system for students, faculty and administrators, with a separate portal for each role and Firestore security rules behind it.

Implemented (per README)

  • Role-based portals: profile documents with a student, faculty or admin role decide which portal a user reaches.
  • Firestore collections for profiles, courses, enrollments, attendance sessions, attendance records and marks.
  • Firebase Authentication with email and password, plus firestore.rules for per-role and per-owner access.
  • Documented deployment checks for authentication, role routing and Firestore access.

Stack

  • Next.js
  • React
  • TypeScript
  • Firebase Auth
  • Cloud Firestore
  • Firebase Admin
  • Vercel

Honest limits

Published as a demo. It is not described as an official IIT Bhilai system, and no adoption, user numbers or institutional endorsement are claimed. The README asks for authorised and unauthorised paths to be tested before treating any deployment as ready.

Territory 04

NextMarga

Active development · live demo

A student-focused platform for discovering scholarships, competitions, exams, internships, research programs and hackathons, with a profile, roadmap, application tracking and an AI career assistant.

Problem (per README)

Students often search dozens of websites for opportunities that match their class, interests, location and goals. NextMarga aims to bring that into one personalised flow.

Implemented (per README)

  • Opportunity search and filtering with category browsing and deadline information.
  • Student profile with education, interests, skills and goals, plus an onboarding wizard.
  • Roadmap, applications and dossier screens.
  • CareerAI chat and assessment endpoints behind a server API that validates requests before calling Gemini.
  • Supabase authentication and data with Row Level Security; PWA support and a Capacitor Android project.

Stack

  • React 19
  • TypeScript
  • Vite
  • Tailwind CSS v4
  • Express server
  • Supabase
  • Gemini (@google/genai)
  • Capacitor
  • PWA

Honest limits

The README calls it "actively developed" and says opportunity coverage is still evolving. AI guidance is assistance; eligibility and deadlines should be checked against official sources.
