Selected work

01

Koinelio

Campus community platform · Next.js, Supabase

In progress · pilot

A Supabase-backed campus platform: profiles, approved clubs, student leadership, events, notifications and role-restricted club rooms.

Built

  • Sign-up restricted to confirmed @iitbhilai.ac.in accounts; sign-up can only create students.
  • Profile editing and avatar upload; posts, likes, comments, events and notifications.
  • Club proposals, invitations, Core Member assignment and governance approvals.
  • Three club rooms gated by Postgres Row Level Security; moderator-only report handling.

Engineering note

Privileges come only from database workflows — never from client-supplied sign-up metadata.

Unresolved

The README calls this production hardening: migrations are not validated on staging or applied to the live Supabase project. Not an official IIT Bhilai service.

ASRS

Student records & attendance · Next.js, Firebase

Demo

Attendance and academic records for students, faculty and administrators, with a separate portal per role.

Built

  • Role documents (student / faculty / admin) decide which portal a user reaches.
  • Firestore collections for profiles, courses, enrollments, sessions, records and marks.
  • Firebase email/password auth with rules for role and ownership access.

Unresolved

Published as a demo — not described as an official IIT Bhilai system, with no adoption, user counts or endorsement claimed.

04

NextMarga

Opportunity discovery · React, Express, Gemini

Active development

Students search dozens of sites for scholarships, competitions, exams and internships. NextMarga pulls that into one flow with a profile, roadmap, applications and an AI assistant.

Built

  • Opportunity search and filtering with category browsing and deadlines.
  • Profile and onboarding wizard, roadmap, applications and dossier screens.
  • CareerAI endpoints behind a server boundary that validates before calling Gemini.
  • Supabase auth and data with RLS; PWA support and a Capacitor Android project.

Engineering note

Keys never reach the client: AI requests pass through api/chat.ts and api/assess-response.ts.

Unresolved

Its README calls it actively developed and says opportunity coverage is still evolving. AI guidance is assistance — eligibility and deadlines must be checked at the source.
