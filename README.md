# Kaif Ali — Portfolio

A polished, responsive developer portfolio for **Kaif Ali**, an Electrical Engineering student at IIT Bhilai and developer focused on full-stack web development, DSA, AI-powered products and practical software engineering.

## ✨ Included

- Professional dark, responsive portfolio UI
- Hero section with GitHub profile avatar
- About, skills, projects, journey and certifications sections
- Real GitHub project links
- NextMarga, SmartNotepad, SkyLume Weather and Tech Cafe highlights
- GitHub, LinkedIn and Instagram contact links
- Accessible navigation and mobile menu
- Scroll reveal animations
- SEO/Open Graph metadata
- Zero backend dependency — ready for static deployment

## 🧰 Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Vercel-ready static deployment

## 🚀 Run locally

Because this is a static site, it can be opened directly in a browser. For a local development server, use any static server, for example:

```bash
npx serve .
```

## 🌐 Deploy

The project is designed to deploy directly from GitHub to Vercel with no build command required.

### Vercel settings

- Framework preset: **Other**
- Build command: **None**
- Output directory: **`.`**
- Install command: **None**
